# The Locked Studio

An escape room that reviews the nine principles of design (balance, contrast, emphasis, alignment, unity, repetition, movement, pattern, proximity) for MYP Digital Design.

Each of the nine doors has a multi-round puzzle on the page and a task students complete in Canva. Finishing both earns a letter. The nine letters are scrambled and spell the exit code.

- Single file, no build step: open `index.html` or visit the GitHub Pages site.
- Progress saves in the browser (localStorage), so students can continue on another day.
- Canva task numbers come in three versions per student, so neighbors get different answers.
- Teacher preview: add `#teacher` to the end of the URL to show skip and fill-answer buttons.
